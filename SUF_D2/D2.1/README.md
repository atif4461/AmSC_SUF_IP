# AmSC SUF NP Demonstrator D2.1 (Flask)

## Run locally

1. Create and activate a Python environment.
2. Install dependencies:
   - `pip install -r requirements.txt`
3. Start the server:
   - `python app.py`
4. Open:
   - http://127.0.0.1:5000

## Included UI sections

- Overview (informative placeholder content)
- Configuration
  - Select existing configuration
  - Add New... modal
  - Edit selected configuration modal
  - Continue button
- Workflow Execution
  - Initially inactive
  - Activates only after `Continue`
  - Buttons: Check components, Run Workflow ..., Cancel
  - Component status table

The UI currently uses in-browser placeholder behavior and can be connected to backend APIs in a later step.
